Rihito's projects

Projects by Rihito (ALI-IOI), a CSE student in Bangladesh: a cafeteria pre-order system in C++ running as WebAssembly, an orthogonal-trajectories solver, and a robotics learning journal.

Projects

  • Cafeteria Pre-Order System (C++): University cafeteria pre-order system (BAUSTK, DSA I): a C++17 server on hand-built data structures. Live demo runs in your browser via WebAssembly. Source
  • Infinite Approximation (C++): Type a family of curves, see its orthogonal trajectories. All maths in C++ compiled to WebAssembly. Source
  • Rihito's Journal (JavaScript): My Flight Path 2029 robotics tracker, from Arduino to ESP32, ROS 2, drones and a research Masters. Source
  • Home page (HTML): this site, a coverless grimoire of my projects. Source

Full list of repositories: github.com/ALI-IOI.
